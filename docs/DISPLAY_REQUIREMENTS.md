# CORD Display System 显示与配置需求（DISPLAY_REQUIREMENTS）

版本：v1.0（草案）
更新日期：2026-09-04
适用范围：门店常驻展示屏的 `/display` 显示端，以及 `/admin` 配置端相关能力。
状态：需求确认完成，待进入开发。

---

## 0. 名词与总原则

- **视觉区（visual）**：`now_playing` 场景左侧承载图像/视频的区域。
- **信息区（copy）**：`now_playing` 场景右侧承载曲目信息、演出提示的文字区域。
- **全屏场景**：`promotion` / `store_event` / `ambient`，主体是一张接近全屏的图片或视频。
- **主色（dominant color）**：从素材（视频取首帧）采样得到的代表色，用于背景填充。
- **中段插播**：曲子播放到一半时，把 `now_playing` 左侧视觉区临时替换为素材的行为。
- **场景插播**：曲子自然播完时，整屏切换到 `promotion` / `store_event` 展示若干秒的行为。

总原则：
1. 只维护一套前端与一套状态协议，平台差异只在数据源层。
2. 用「比例白名单」从源头约束素材，尽量让素材贴合显示区，减少背景填充面积。
3. 背景填充只处理残余边条，取色失败一律回退到安全底色，绝不出现纯黑突兀边。
4. 左右分区必须拼满整屏，无空隙。

## 1. 场景清单

| 场景 | 键值 | 布局 | 主体内容 | 触发方式 |
|---|---|---|---|---|
| 正在播放 | `now_playing` | 左视觉 + 右信息 | 左：专辑封面／中段插播素材；右：曲目信息（命中歌手时追加演出提示） | 常态。右侧随曲目实时更新 |
| 门店推荐 | `promotion` | 近全屏单图 | 产品／豆子推荐图 | 场景插播（曲末）／手动预览 |
| 门店活动 | `store_event` | 近全屏单图（设计同 promotion） | 促销／活动图 | 场景插播（曲末）／手动预览。与 promotion 随机混播 |
| 门店宣传 | `ambient` | 全屏居中 | 常驻宣传图／视频 | 常驻，低频更换 |

说明：
- 原独立的 `artist_notice` 场景**取消**，其内容并入 `now_playing` 右侧作为增量信息块。
- `store_event` 是新增场景，数据结构与调度与 `promotion` 并行，插播时两类物料**随机混在一起**取。

## 2. 场景滚动顺序（时序）

保留核心时序：正在播放（当前曲）→ 曲末自然结束 → 展示界面（推荐/活动）→ 回到正在播放（新曲）。

```
now_playing(曲A) ──曲A自然播完──> 场景插播(promotion 或 store_event, 随机, 停留 N 秒) ──> now_playing(曲B)
```

`ambient` 门店宣传为常驻独立展示，由后台手动切入/切出，不参与上面的自动滚动。

## 3. now_playing —— 左侧视觉区

### 3.1 常态

左侧默认显示**当前曲目的专辑封面**（`track.cover_url`），随换歌自动更新。右侧显示曲目信息。

### 3.2 视觉模式（后台可选，全局配置）

| 模式 | 键值 | 左侧内容 |
|---|---|---|
| 跟随封面（默认） | `album_cover` | 当前曲专辑封面（1:1） |
| 自定义图片 | `image` | 后台指定图片 |
| 自定义视频 | `video` | 后台指定视频（muted loop） |

### 3.3 比例白名单（左侧视觉素材必须符合）

左侧视觉区宽度由所选比例决定，右侧信息区吃掉剩余宽度，保证左右拼满整屏无空隙。素材仅允许以下比例，符合即按比例等比缩放贴合，比例不符则后台上传时提示：

| 比例 | 典型分辨率 | 用途 |
|---|---|---|
| 1:1 | 1080×1080、1254×1254 | 专辑封面、方图海报 |
| 3:4 / 4:3 | 1080×1440 / 4000×3000 | 常规竖/横海报 |
| 2:3 | 1080×1620 | 竖版海报 |
| 9:16 | 1080×1920 | 竖屏海报 |
| 9:19.5 | 1080×2340 | 现代手机海报 |

### 3.4 中段插播（左侧视觉区的轮播策略）

触发与计时规则：
1. 仅当**当前曲总时长 > `insert_min_song_seconds`**（后台配置）时，该曲才可能触发中段插播。
2. 触发点由 `insert_at_percent`（后台配置，默认 50%）决定，即播放进度到达该百分比时触发。
3. 触发后，左侧视觉区临时替换为一条插播素材（图/视频），停留 `insert_hold_seconds`（后台配置）。
4. 停留期间**右侧曲目信息照常实时更新**，不受影响。
5. 停留结束后，左侧自动切回**当时正在播放的那首歌的专辑封面**。

跨曲延续规则（重点）：
- 插播按**绝对停留时长**计时，不因换曲而中断或重置。
- 若「触发点 + 停留时长」超出当前曲剩余时间，插播**继续延续到下一首歌**播放，直到停留时长走完；结束后左侧切回**下一首歌的专辑封面**（不是已放完的那首）。
- 若插播延续期间，下一首歌又满足触发条件：**插播进行中忽略新触发**；等本段插播完整结束、切回封面后，再按正常节奏计算下一次触发。

```
曲A(够长) ──到触发点──┐
                     │  左侧=插播素材   右侧=曲A信息
曲A播完→换曲B ─────────┤  左侧仍=素材(延续) 右侧=曲B信息（B若也够长，其触发被忽略）
                     │
停留时长到 ────────────┘  左侧切回“曲B专辑封面”  右侧=曲B信息
```

### 3.5 演出提示（并入右侧信息区）

- 当当前曲目歌手命中已登记的演出事件时，右侧在常规曲目信息之外**追加**一块「ARTIST IN TOWN + 演出详情」信息块。
- 展示时机：**只要命中就一直挂在右侧**，直到换到不再命中的曲目才移除。不做淡入淡出的定时收起。
- 未命中时右侧只显示常规曲目信息。左侧视觉区不受演出提示影响。

### 3.6 左右分区背景方案（各含一套备选，基于品牌色板）

now_playing 分区底色分左右两块，各自在**默认方案**外多备**一套备选方案**。此处指分区底色（最底层打底），与第 5 节封面取色补边是不同层级：底色打底 → 封面取色补边叠在左侧底上 → 封面本体。

四套方案配色示例图：`docs/assets/now-playing-bg-schemes.png`（左侧默认暖米/冲突时切中性灰底；右侧默认近黑/备选暖米亮底）。

左侧视觉区（承载专辑封面）：
- 默认底：暖米卡其 `#D9C486`（khaki），配砖红字标元素。
- 备选底：当默认底与专辑封面主色**冲突**时**自动切换**到一套不冲突的底（建议中性冷灰或近黑，与封面拉开明度）。
- **冲突定义**：取专辑封面主色明度与左侧底色明度，两者明度差 < 阈值 `visual_bg_conflict_threshold`（默认 0.15，即封面与底色明暗太接近、封面边缘糊进底里）判为冲突。冲突时按封面明暗反向选备选底（封面偏亮→切较暗底，封面偏暗→切较亮中性底），保证封面轮廓清晰。

右侧信息区（承载文字）：
- 默认底：logo 黑 `#040000`（ink），配浅色字（现用近黑 `#171713` 逐步校准到 `#040000`）。
- 备选底：一套**更明亮**的方案，**手动在 admin 二选一**（非自动）。建议用品牌暖米卡其 `#D9C486` 或砖红 `#B03D25` 作亮底；启用亮底时字色须对应改深（暖米底→砖红/近黑字，砖红底→近黑字），遵循 5A 的官方配对，保证可读性与对比。

### 3.7 专辑图尺寸档位（后台可调，四档）

左侧专辑封面/视觉素材大小由后台 `visual_size` 选择，四档离散值，控制素材占视觉区高度的比例（宽度仍由所选比例白名单决定）：

| 档位 | 占视觉区高度 | 观感 |
|---|---|---|
| `small` | ≈55% | 画廊留白最多，露出最多取色背景 |
| `medium`（默认） | ≈72% | 均衡（≈现状 `min(36vw,72vh)`） |
| `large` | ≈88% | 素材突出，留白少 |
| `fill` | 100% | 贴满视觉区高度，露边最少 |

档位越小、封面周围露出的取色/底色背景越多，与 3.6 的分区底色和第 5 节取色补边配合呈现。

## 4. 全屏场景规格（promotion / store_event / ambient）

### 4.1 屏幕基准

以门店屏实际方向为准（横屏 16:9 或竖屏 9:16，见待确认项）。全屏场景素材比例应贴近屏幕比例以减少填充。

### 4.2 全屏素材比例白名单

| 比例 | 方向 | 说明 |
|---|---|---|
| 16:9 | 横 | 横屏主推 |
| 16:10 | 横 | 横屏容错 |
| 9:16 | 竖 | 竖屏主推 |
| 4:3 / 3:4 | 横/竖 | 容错 |

### 4.3 缩放策略

- 素材比例与屏幕比例差值 **≤ `fullscreen_fit_threshold`（默认 0.05）→ 用 `cover` 铺满**（几乎无裁切）。
- 差值 **> 阈值 → 用 `contain` 居中**，四周用取色补边（不裁切内容）。
- `ambient` 门店宣传固定 **`contain` 居中**，保证整图/整片完整可见。
- `ambient` 视频：`contain` 居中、`muted loop`，取首帧主色补边。

## 5. 背景取色与填充策略

### 5.1 取色来源

- 优先**前端 Canvas 采样**：图片直接采样，视频取首帧，降采样后统计主色。性能开销小，门店屏常驻停留久，完全够用。
- 无法取色（跨域受限 / SVG / 采样失败）→ 回退安全底色。

### 5.2 两套方案 + 开关

| 方案 | 键值 | 算法 | 观感 |
|---|---|---|---|
| 相近色（默认） | `analogous` | 主色降饱和 + 压暗 | 自然、不抢镜 |
| 对比色 | `contrast` | 主色取补色 + 压暗 | 强调、有张力 |

两套方案的实际观感对比（示例图）：`docs/assets/bg-fill-comparison.png`（左：相近色，边框与主体柔和融合；右：对比色，冷色边框衬托暖色主体形成张力）。

由后台 `bg_fill_mode` 切换。**当前全局生效**（所有场景统一用同一方案），但取色能力在实现上要设计成**独立、可复用的模块**：取色与填充逻辑不与具体场景耦合，`bg_fill_mode` 作为一个可被"作用域"覆盖的参数传入。这样将来要做分场景独立计算时，只需把作用域从"全局单值"扩展为"每场景一份配置"，无需改动取色核心逻辑（见待确认项 2 与第 5.5 节）。

### 5.3 安全底色（回退）

沿用品牌色：深色底 `--ink (#171713)`、暖色底 `--khaki (#d9c486)`。取色失败时按场景选用其一。

### 5.4 应用位置

- `now_playing` 左侧视觉区素材不满区域时的补边。
- 全屏场景 `contain` 模式的四周留白。

### 5.5 取色模块的独立设计（为分场景扩展预留）

为便于将来从"全局一个开关"平滑扩展到"每场景独立计算"，取色能力按如下契约实现，与场景解耦：

- **纯函数内核**：`resolveFillColor(sample, { mode }) -> color`。输入为素材采样得到的主色（或视频首帧主色），输出为最终填充色。内部只依赖 `mode`（`analogous` / `contrast`）与主色，不感知"这是哪个场景"。
- **作用域解析层**：`getFillMode(scene) -> mode`。当前实现直接返回全局 `config.bg_fill_mode`，忽略 `scene` 参数；将来扩展时改为"先查该场景的独立配置、缺省再回落全局"，调用方无需改动。
- **回退内建在内核**：采样为空/失败时内核直接返回安全底色，调用方不处理回退分支。
- **无状态、可缓存**：同一素材 + 同一 mode 结果稳定，可按素材 URL 缓存主色，避免重复采样。

这样，分场景独立计算在数据层只是把 `bg_fill_mode` 从单一字符串扩展为 `{ default, per_scene: {...} }` 结构，取色内核与调用点均无需重写。

## 6. 曲末场景插播（promotion / store_event）

沿用并扩展现有调度：
- 开关：`auto_insert_enabled`。
- 触发：当前曲**自然播完**（换曲/停止/重头开始且已接近结束）。
- 限流：距上次插播 ≥ `insert_min_interval_minutes`；且每小时非音乐占比不超过 `non_music_hourly_max_percent`。
- 取素材：从 `promotion` 与 `store_event` 两类**有效物料中随机混选**一条，停留该物料的 `display_seconds` 秒，结束切回 now_playing 新曲。

## 7. 配置项汇总

所有配置走 `POST /api/config`，持久化到 `data/runtime-config.json`，`/admin` 提供表单。

| 字段 | 含义 | 取值 / 默认 |
|---|---|---|
| `visual_mode` | 左侧视觉模式 | `album_cover`(默认) / `image` / `video` |
| `visual_url` | 自定义素材地址 | 字符串，默认空 |
| `visual_aspect` | 左侧视觉比例 | 白名单枚举，默认 `1:1` |
| `visual_size` | 专辑图尺寸档位 | `small` / `medium`(默认) / `large` / `fill` |
| `visual_bg_conflict_threshold` | 左侧底色与封面主色冲突判定的明度差阈值 | 0–1，默认 0.15 |
| `right_bg_variant` | 右侧信息区背景方案 | `dark`(默认，ink 近黑) / `bright`(暖米/砖红亮底) |
| `bg_fill_mode` | 背景填充方案（封面取色补边） | `analogous`(默认) / `contrast` |
| `fullscreen_fit_threshold` | cover/contain 切换阈值 | 0–1，默认 0.05 |
| `insert_min_song_seconds` | 触发中段插播的最短曲长 | 秒，默认 240 |
| `insert_at_percent` | 中段插播触发点 | 0–100，默认 50 |
| `insert_hold_seconds` | 中段插播停留时长 | 秒，默认 20 |
| `auto_insert_enabled` | 曲末场景插播开关 | 布尔，默认 true |
| `insert_min_interval_minutes` | 场景插播最小间隔 | 分钟，默认 20 |
| `non_music_hourly_max_percent` | 每小时非音乐占比上限 | 0–20，默认 10 |
| `ambient_media_url` | 常驻宣传素材地址 | 字符串，默认空 |
| `ambient_media_type` | 常驻宣传素材类型 | `image` / `video` |
